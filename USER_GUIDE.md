# AutoTestGenerator — Руководство пользователя

Информационная система автоматической генерации UI-автотестов для веб-приложений E3Core из XML-метамодели.

Программа на JavaFX. Это руководство описывает установку и работу под **Windows 10/11**.

> 💡 **Самый простой путь на «пустом» Windows** — портативный комплект, без ручной установки
> Java/Maven и без Git: распакуйте папку и запустите `1_УСТАНОВКА.bat`, затем `2_ЗАПУСК.bat`.
> Понадобятся только Google Chrome и интернет. Подробно и с пояснениями — в файле
> **`РУКОВОДСТВО.html`** (откройте двойным кликом). Инструкция ниже — для ручной установки.

---

## 1. Системные требования

| Компонент             | Минимум                     | Зачем                                                            |
| --------------------- | --------------------------- | ---------------------------------------------------------------- |
| ОС                    | Windows 10 / 11 (64-бит)    | Тестировалось на Windows 10/11                                   |
| Оперативная память    | 4 ГБ (рекомендуется 8 ГБ)   | JVM + Chrome для прогона тестов                                  |
| Свободное место       | 2 ГБ                        | JDK + Maven-зависимости + сгенерированные тесты + скриншоты      |
| Java JDK              | **17 или новее**            | Программа собрана под Java 17                                    |
| Apache Maven          | **3.8+**                    | Сборка программы и запуск сгенерированных тестов                 |
| Git                   | Любая актуальная версия     | Клонирование репозитория                                         |
| Google Chrome         | **Актуальная версия**       | Selenium запускает реальный Chrome для прохождения тестов        |
| Интернет              | Нужен при первом запуске    | Maven скачает зависимости (~150 МБ), WebDriverManager — ChromeDriver |

> **ChromeDriver устанавливать вручную НЕ нужно** — библиотека `WebDriverManager` автоматически скачает подходящую версию под установленный Chrome.

## 2. Установка зависимостей

### 2.1. Установка Java JDK 17+

1. Скачайте **Adoptium Temurin JDK 17 (LTS)** под Windows x64:
   <https://adoptium.net/temurin/releases/?version=17>
2. Запустите установщик `.msi`. На шаге «Custom Setup» включите:
   - **Set `JAVA_HOME` variable** → Will be installed
   - **Add to PATH** → Will be installed
3. Завершите установку и **перезапустите CMD/PowerShell**.

Проверьте установку:

```cmd
java -version
javac -version
```

Ожидаемый вывод (версия может отличаться):

```
openjdk version "17.0.10" 2024-01-16
OpenJDK Runtime Environment Temurin-17.0.10+7
```

> *[Скрин: окно CMD с успешным выводом `java -version`]*
> ![](screenshots/01-java-version.png)

---

### 2.2. Установка Apache Maven

1. Скачайте бинарный архив Maven с официального сайта:
   <https://maven.apache.org/download.cgi> → **Binary zip archive** (например `apache-maven-3.9.6-bin.zip`).
2. Распакуйте архив, например в `C:\tools\apache-maven-3.9.6`.
3. Добавьте Maven в `PATH`:
   - **Win + R** → `sysdm.cpl` → вкладка **Дополнительно** → **Переменные среды**.
   - В разделе «Системные переменные» выберите `Path` → **Изменить** → **Создать** → вставьте путь `C:\tools\apache-maven-3.9.6\bin`.
   - ОК → ОК. **Перезапустите CMD**.

Проверка:

```cmd
mvn -v
```

Ожидаемый вывод:

```
Apache Maven 3.9.6
Maven home: C:\tools\apache-maven-3.9.6
Java version: 17.0.10, vendor: Eclipse Adoptium
```

> *[Скрин: окно CMD с успешным выводом `mvn -v`]*
> ![](screenshots/02-maven-version.png)

---

### 2.3. Установка Git

1. Скачайте **Git for Windows**: <https://git-scm.com/download/win>
2. Запустите установщик. Все галочки по умолчанию подходят. На шаге выбора редактора можно оставить «Vim» или сменить на «Notepad».
3. Завершите установку. Появится **Git Bash** в меню «Пуск».

Проверка:

```cmd
git --version
```

> *[Скрин: окно CMD с выводом `git --version`]*
> ![](screenshots/03-git-version.png)

---

### 2.4. Установка Google Chrome

Если Chrome уже установлен и обновлён до актуальной версии — пропустите этот шаг.

1. Скачайте Chrome: <https://www.google.com/chrome/>
2. Установите. После установки проверьте версию: **⋮ → Справка → О браузере Google Chrome** — должна быть актуальная.

> *[Скрин: страница "О Chrome" с версией]*

## 3. Клонирование репозитория

1. Откройте CMD или PowerShell в удобной папке, например `C:\Projects`:

   ```cmd
   cd C:\
   mkdir Projects
   cd Projects
   ```

2. Клонируйте репозиторий и переключитесь на ветку `vers2`:

   ```cmd
   git clone https://github.com/nastolbov/AutoTestGenerator.git
   cd AutoTestGenerator
   git checkout vers2
   ```

3. Проверьте, что вы на нужной ветке:

   ```cmd
   git branch
   ```

   Должна быть отмечена `* vers2`.

> *[Скрин: успешный `git clone` + `git checkout vers2`]*
> ![](screenshots/05-git-clone.png)

## 4. Сборка и запуск программы

### 4.1. Первый запуск (скачивание зависимостей)

В корне репозитория (`C:\Projects\AutoTestGenerator`) выполните:

```cmd
mvn clean compile
```

Первый запуск скачает Maven-зависимости (~80 МБ): JavaFX, SQLite JDBC и пр. Это может занять 1–3 минуты в зависимости от скорости интернета.

Успешный финал:

```
[INFO] BUILD SUCCESS
[INFO] Total time:  XX.XXX s
```

> *[Скрин: завершение `mvn clean compile` с BUILD SUCCESS]*
> ![](screenshots/06-mvn-compile.png)

### 4.2. Запуск GUI

```cmd
mvn javafx:run
```

Через 5–15 секунд откроется главное окно программы.

> *[Скрин: главное окно AutoTestGenerator сразу после запуска]*
> ![](screenshots/07-main-window.png)

## 5. Работа с программой

Главное окно состоит из трёх блоков:

- **Сверху** — параметры запуска (XML, URL, логин/пароль, каталог вывода, кнопки).
- **Слева** — список сущностей из загруженной XML-модели.
- **Справа** — таблица результатов тестов и журнал (лог).

> *[Скрин: главное окно с разметкой блоков (можно подписать вручную)]*
> ![](screenshots/08-layout.png)

### Шаг 1. Выбор XML-модели

1. Нажмите **«Обзор…»** справа от поля **XML-файл**.
2. В диалоге выберите `.xml`-файл вашей метамодели (например, `model.xml` из E3Core).
3. Путь подставится в поле.

> *[Скрин: открытый диалог выбора файла]*
> ![](screenshots/09-select-xml.png)

### Шаг 2. Параметры тестируемого сайта

Заполните:

| Поле               | Описание                                                          |
| ------------------ | ----------------------------------------------------------------- |
| **URL сайта**      | Базовый URL E3Core, например `https://rrpo.cmirit.ru/E3Core`      |
| **Логин**          | Имя пользователя для входа в систему                              |
| **Пароль**         | Пароль                                                            |
| **Каталог вывода** | Куда будет сгенерирован Maven-проект с тестами                    |

По умолчанию каталог вывода — `<текущая папка>\generated-tests`.

> *[Скрин: блок параметров с заполненными полями]*
> ![](screenshots/10-params.png)

### Шаг 3. Разбор XML

Нажмите зелёную кнопку **«Разобрать XML»**.

Если файл корректен — в журнале появится:
```
XML разобран успешно. Найдено сущностей: N, поисков: M
```
В левой панели появится список сущностей, например:
```
Должностное лицо [CRUD] (12 полей)
Адрес (5 полей)
ГСК/ОГСК [CRUD] (8 полей)
```

> *[Скрин: список сущностей появился слева, в логе сообщение "XML разобран"]*
> ![](screenshots/11-parsed.png)

### Шаг 4. Выбор уровня тестов

В выпадающем списке **«Уровень тестов»** выберите один из:

| Уровень   | Что входит                                                               |
| --------- | ------------------------------------------------------------------------ |
| **SMOKE** | Минимальный набор: открытие подсистемы, базовая навигация. Самый быстрый.|
| **BASIC** | Основные сценарии: создание, обновление, удаление, поиск (по умолчанию). |
| **FULL**  | Все сценарии: + валидация, + логическое удаление, + архивирование и т.д. |

Галка **«Smoke по всем подсистемам»** — для SMOKE автоматически пройти по всем доступным подсистемам, а не только по той, что в XML.

### Шаг 5. Генерация тестов

Нажмите синюю кнопку **«Сгенерировать тесты»**.

В журнале появится:
```
Уровень тестов: BASIC
Сгенерировано тестовых классов: N
Тесты сгенерированы в: C:\Projects\AutoTestGenerator\generated-tests
```

Кнопки «Запустить тесты» и «Выбрать тесты…» станут активными.

> *[Скрин: сообщение "Тесты сгенерированы" в логе, оранжевые кнопки активны]*
> ![](screenshots/12-generated.png)

### Шаг 6. Запуск тестов

**Вариант А — запустить всё:** нажмите оранжевую кнопку **«Запустить тесты»**.

**Вариант Б — выборочный запуск:** нажмите **«Выбрать тесты…»** — откроется диалог. Слева отметьте нужные сущности, справа — виды тестов (создание, удаление, поиск и т.д.). Внизу диалога — live-превью фильтра, который будет передан Surefire. Нажмите **«Запустить»**.

> *[Скрин: диалог "Выбор тестов для запуска" с отмеченными сущностями и типами]*
> ![](screenshots/13-select-tests.png)

Опционально — галка **«Быстрый режим (3×headless)»** запускает тесты в 3 параллельных Chrome-инстансах без визуального окна (даёт прирост ×3–4 по скорости).

В процессе запуска:
- Внизу окна крутится индикатор прогресса.
- В журнале появляются строки `mvn test`.
- Открывается окно Chrome (если не включён быстрый режим) — **не закрывайте его руками**, Selenium управляет им сам.

> *[Скрин: тесты идут, Chrome открыт, в логе вывод Maven]*
> ![](screenshots/14-running.png)

### Шаг 7. Результаты

После завершения:
- В таблице результатов появится строка на каждый тест: **класс / метод / статус (OK/FAIL/SKIP) / время / сообщение**.
- Цветовая подсветка: зелёный = OK, жёлтый = SKIP, красный = FAIL.
- Сверху таблицы — счётчики «Всего / Успешно / Ошибки».

> *[Скрин: заполненная таблица результатов с разноцветными статусами]*
> ![](screenshots/15-results.png)

В журнале будут пути к отчётам:

```
HTML-отчёт (v5, с фотолетописью): ...\generated-tests\target\run-report.html
HTML-отчёт (стандартный surefire): ...\generated-tests\target\site\surefire-report.html
CSV-отчёт: ...\generated-tests\target\run-report.csv
Скриншоты: ...\generated-tests\target\screenshots\
```

### Шаг 8. Просмотр HTML-отчёта

Откройте в браузере файл `generated-tests\target\run-report.html`.

Отчёт содержит:
- Сводку прогона (всего/успешно/ошибки/время).
- Развёрнутые карточки тестов с шагами, скриншотами и stdout.
- Подсветка упавших тестов с сообщением об ошибке.

> *[Скрин: открытый run-report.html в браузере]*
> ![](screenshots/16-html-report.png)

### Шаг 9. История прогонов

Нажмите кнопку **«История прогонов»** — в журнале выведется список всех ранее сохранённых запусков (из SQLite-базы `autotestgen.db`):

```
[2026-06-06T15:42:11] XML: model.xml | URL: ... | Всего: 24 | OK: 22 | Ошибки: 2 | Время: 184320 мс
[2026-06-06T14:10:55] ...
```

В таблицу автоматически загрузятся результаты последнего прогона.

> *[Скрин: журнал с историей прогонов + загруженная таблица последнего]*
> ![](screenshots/17-history.png)

## 6. Возможные ошибки и их решение

| Симптом                                                                 | Причина                                                | Что делать                                                                 |
| ----------------------------------------------------------------------- | ------------------------------------------------------ | -------------------------------------------------------------------------- |
| `'mvn' не является внутренней или внешней командой`                     | Maven не добавлен в `PATH`                             | Перечитайте раздел 2.2, перезапустите CMD                                  |
| `'java' не является внутренней или внешней командой`                    | JDK не установлен или нет в `PATH`                     | Переустановите Temurin JDK 17, отметив «Add to PATH»                       |
| `Error: JavaFX runtime components are missing`                          | Запускали через `java -jar`, а не `mvn javafx:run`     | Используйте `mvn javafx:run`                                               |
| Окно открылось, но кнопка «Разобрать XML» выдаёт «Файл не найден»       | Указан неверный путь / файл переместили                | Нажмите «Обзор…» и выберите файл заново                                    |
| `BUILD FAILURE` при генерации тестов                                    | Каталог вывода защищён от записи                       | Укажите другой каталог (например, `C:\Users\<имя>\Documents\autotests`)    |
| Тесты падают с `SessionNotCreatedException` / mismatch ChromeDriver     | Версия Chrome обновилась, кэш WebDriverManager устарел | Удалите папку `%USERPROFILE%\.cache\selenium\` и перезапустите тесты      |
| `mvn test` зависает на «Downloading…»                                   | Слабый/нестабильный интернет                           | Дождитесь скачивания (только при первом запуске; потом всё из локального `.m2`)|
| Тесты упали, но скриншотов нет                                          | Закрыли окно Chrome руками во время прогона            | Не трогайте окно Chrome во время теста                                     |
| В таблице везде SKIP                                                    | XML не содержит CRUD-операций или сущности классифицированы как REFERENCE_DICTIONARY/CHILD | Проверьте XML; в логе будут причины skip                                    |

## 7. Структура каталогов после работы программы

```
AutoTestGenerator\
├── src\                          ← исходники программы
├── pom.xml                       ← Maven-конфиг программы
├── autotestgen.db                ← SQLite с историей прогонов
├── generated-tests\              ← сюда генерируются тесты (по умолчанию)
│   ├── pom.xml                   ← Maven-конфиг сгенерированного проекта
│   ├── src\test\java\generated\  ← Page Objects + JUnit-тесты
│   └── target\
│       ├── run-report.html       ← красивый HTML-отчёт (v5)
│       ├── run-report.csv        ← CSV-выгрузка
│       ├── site\surefire-report.html ← стандартный отчёт Maven
│       ├── surefire-reports\     ← XML-отчёты от Surefire
│       └── screenshots\          ← скриншоты всех шагов всех тестов
```

## 8. Полезные команды

| Команда                            | Что делает                                           |
| ---------------------------------- | ---------------------------------------------------- |
| `mvn clean compile`                | Скачать зависимости и собрать программу              |
| `mvn javafx:run`                   | Запустить GUI                                        |
| `mvn clean`                        | Удалить `target\` (сборочные артефакты)              |
| `git pull origin vers2`            | Получить свежие изменения с GitHub                   |
| `git status`                       | Посмотреть, какие файлы изменены                     |

- Репозиторий: <https://github.com/nastolbov/AutoTestGenerator>

- Текст ошибки из журнала программы.
- Содержимое файла `generated-tests\target\surefire-reports\*.txt` (если упали тесты).
- Версию Windows, JDK (`java -version`), Maven (`mvn -v`) и Chrome.
