## Вероятные вопросы комиссии (подготовьте короткие ответы)
- **Почему StAX, а не DOM?** — потоковый разбор, экономит память на крупной метамодели.
- **Как отличаете основную сущность от справочника?** — по признакам метамодели: пункт меню + собственный CRUD → основная; вкладка‑грид родителя → дочерняя; служебный признак/только ключ+имя → справочник.
- **Почему свой генератор, а не Katalon/Selenide?** — ни один аналог не строит тесты по пользовательской XML‑модели и не создаёт готовый проект (слайд 3).
- **Почему Page Object?** — разделение «страница ↔ тест», переиспользование локаторов, простота сопровождения.
- **В чём экономия?** — ручное написание Page Object и тестов на десятки сущностей — это дни работы; генерация — секунды (окупаемость 1,8 года).
