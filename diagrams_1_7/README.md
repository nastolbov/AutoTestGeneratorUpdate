# Раздел 1.7 — программа и методика испытаний (по образцу раздела 7 Сафиуллина)

Раздел 1.7 для AutoTestGenerator, оформленный по образцу «правильного» раздела 7
из ВКР Сафиуллина. Структура и методы испытаний — те же, содержание — по нашему
коду (`ru.autotestgen.*`), модульной структуре (1.5.3) и ТЗ (Приложение 1).

## Структура
- 1.7.1 Объект и цель испытаний.
- 1.7.2 Требования (6 подпунктов: функциональные, надёжность, условия эксплуатации,
  технические средства, совместимость, документация).
- 1.7.3 Состав, порядок и методы испытаний (ручной контроль + автономное /
  комплексное / системное; методы граничных значений и контрольных примеров;
  системные испытания — на ПК с минимальными характеристиками из ТЗ).
- 1.7.4 Результаты — три таблицы (5 столбцов: Дата | Тестирование проводил |
  Описание теста | Ожидаемый результат | Результат тестирования):
  - **Таблица 132** — автономное тестирование модулей (модули из модульной структуры);
  - **Таблица 133** — комплексное тестирование межмодульных связей;
  - **Таблица 134** — системное тестирование на соответствие ТЗ (10 функц. + 7 надёжн.).
