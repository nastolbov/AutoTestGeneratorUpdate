AutoTestGenerator — руководство для Windows

Программа автоматически создаёт UI-автотесты для веб-приложения E3Core из XML-модели метаданных и сразу запускает их в браузере, показывая отчёт со скриншотами.

Самое главное. На «пустом» компьютере вам нужно сделать всего две вещи руками: установить Google Chrome и иметь интернет. Java и Maven программа поставит сама — через файл 1_УСТАНОВКА.bat.

Что должно быть на компьютере

КомпонентНужно ставить вручную?Зачем

Если Chrome ещё не установлен — скачайте его здесь: https://www.google.com/chrome/ и установите.

Как перенести программу на компьютер

1Скачайте папку с программой (без всякого Git):

  1. Откройте страницу проекта на GitHub.
  2. Нажмите зелёную кнопку Code → Download ZIP.
  3. Перенесите скачанный ZIP на нужный компьютер (флешка, сеть, почта).

2Распакуйте ZIP в простую папку, например C:\AutoTest.

Старайтесь, чтобы в пути не было русских букв и пробелов (C:\AutoTest — хорошо; C:\Мои файлы\тест — может мешать).

Запуск — всего 2 шага

1Двойной клик по 1_УСТАНОВКА.bat

Откроется чёрное окно. Скрипт скачает Java 17 и Maven в подпапку tools\ и подготовит зависимости. Это занимает примерно 3–5 минут (зависит от скорости интернета).

Дождитесь надписи:

  ГОТОВО! Окружение установлено.
  Теперь запустите файл  2_ЗАПУСК.bat

Этот шаг нужен только один раз. При повторных запусках сразу используйте шаг 2.

2Двойной клик по 2_ЗАПУСК.bat

Через 10–20 секунд откроется главное окно программы.

Не закрывайте чёрное окно консоли, пока работаете с программой — через него программа управляет тестами. Закрытие консоли закроет и программу.

Как пользоваться программой

  1. XML-файл — нажмите «Обзор…» и выберите файл модели (в комплекте есть пример 5EA195D102D1_Stc (1).xml). Затем нажмите «Разобрать XML» — слева появится дерево сущностей.
  2. URL сайта, Логин, Пароль — адрес стенда E3Core и учётные данные (по умолчанию уже заполнен тестовый стенд).
  3. Каталог вывода — папка, куда сложить сгенерированный проект тестов (например C:\AutoTest\out).
  4. Нажмите «Сгенерировать тесты» — программа создаст проект тестов.
  5. Нажмите «Запустить тесты» (или «Выбрать тесты…» для части) — откроется Chrome и начнётся прогон. Галочка «Быстрый режим (headless)» прячет окно браузера (чуть быстрее).
  6. Справа в реальном времени видны результаты (успех/ошибка) и журнал.

Если что-то пошло не так

Синее окно «Windows защитила ваш компьютер» (SmartScreen)

Это нормально для скачанных .bat-файлов. Нажмите «Подробнее» → «Выполнить в любом случае».

Ошибка скачивания в 1_УСТАНОВКА.bat

Нет интернета или он ограничен (корпоративный прокси/файрвол). Проверьте подключение, при необходимости отключите VPN и запустите 1_УСТАНОВКА.bat снова.

2_ЗАПУСК.bat пишет «Сначала запустите 1_УСТАНОВКА.bat»

Папка tools\ не создана или установка не завершилась. Запустите 1_УСТАНОВКА.bat и дождитесь надписи «ГОТОВО».

Тесты не запускаются / ошибка про браузер

Убедитесь, что установлен Google Chrome и есть интернет (при первом прогоне автоматически скачивается драйвер ChromeDriver под вашу версию Chrome).

Антивирус блокирует .bat

Добавьте папку программы (например C:\AutoTest) в исключения антивируса.

Более подробное описание (включая ручную установку Java/Maven без скриптов) есть в файле USER_GUIDE.md.
