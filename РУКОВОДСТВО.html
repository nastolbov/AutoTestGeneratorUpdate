AutoTestGenerator — руководство для Windows

Программа автоматически создаёт UI-автотесты для веб-приложения E3Core из XML-модели метаданных и сразу запускает их в браузере, показывая отчёт со скриншотами.

Самое главное. На «пустом» компьютере вам нужно сделать всего две вещи руками: установить Google Chrome и иметь интернет. Java и Maven уже встроены в программу — отдельно ставить ничего не нужно, запуск через двойной клик по AutoTestGenerator.exe.

Что должно быть на компьютере

КомпонентНужно ставить вручную?Зачем

Если Chrome ещё не установлен — скачайте его здесь: https://www.google.com/chrome/ и установите.

Как перенести программу на компьютер

1Получите архив с программой — файл AutoTestGenerator-windows.zip (его передаёт разработчик: флешка, сеть, почта). Внутри уже всё нужное, включая встроенные Java и Maven.

2Распакуйте ZIP в простую папку, например C:\AutoTest.

Старайтесь, чтобы в пути не было русских букв и пробелов (C:\AutoTest — хорошо; C:\Мои файлы\тест — может мешать).

Запуск — один шаг

1Двойной клик по AutoTestGenerator.exe

Файл лежит в папке AutoTestGenerator\. Через 10–20 секунд откроется главное окно программы. Никаких чёрных окон консоли и предварительной установки не требуется.

Первый запуск тестов может занять несколько минут — Maven один раз скачивает нужные библиотеки из интернета. Последующие прогоны идут быстро.

Если у вас Mac

Для macOS есть отдельные сборки — возьмите архив под ваш Mac:

  • AutoTestGenerator-macos-arm64.zip — Apple Silicon (M1/M2/M3…);
  • AutoTestGenerator-macos-x64.zip — Mac на процессоре Intel.

1Распакуйте архив.

2Первый запуск: правый клик (или Ctrl+клик) по AutoTestGenerator.app → «Открыть» → в диалоге ещё раз «Открыть». Приложение не подписано сертификатом, поэтому macOS один раз спрашивает подтверждение (аналог SmartScreen на Windows) — это не вирус.

Если macOS пишет, что приложение «повреждено и не может быть открыто», выполните один раз в Терминале (из папки с приложением): 
xattr -dr com.apple.quarantine AutoTestGenerator.app
и снова откройте приложение. Chrome и интернет нужны так же, как на Windows.

Дерево сущностей (слева)

После «Разобрать XML» слева появляются две группы — «✓ Будут протестированы» и «✗ Тесты не генерируются». Цвет узла показывает его роль:

ЦветЗначение
● зелёныйотдельный тест-класс (основная сущность, PRIMARY)
● янтарныйтест в составе родителя (дочерняя сущность, CHILD). Рядом помечено, как она открывается: (вкладка) или (узел дерева)
● серыйтесты не создаются (справочники, поля-ссылки FK)

Подпись узла имеет вид Имя [CRUD] (N полей): пометка [CRUD] — есть операции создания/изменения/удаления, N полей — сколько отображаемых полей. Наведите курсор на узел — во всплывающей подсказке будет причина классификации.

Например, «Повестка совещания» помечена (узел дерева): в карточке «Совещания» она открывается как ветка в левом дереве, а не как вкладка — поэтому и проверяется иначе, чем соседи.

Пошаговый сценарий работы

  1. «Обзор…» у поля XML-файл → выберите модель → «Разобрать XML».
  2. Посмотрите дерево сущностей слева — что попадёт в тесты, а что нет.
  3. Проверьте URL / Логин / Пароль и Каталог вывода (по умолчанию уже заполнены).
  4. «Сгенерировать тесты» — в каталоге вывода появится проект автотестов.
  5. «Запустить тесты» (все) либо «Выбрать тесты…» (часть). Откроется Chrome и начнётся прогон; ход видно в логе справа снизу.
  6. По завершении смотрите таблицу результатов и отчёты (см. ниже).

Диалог «Выбрать тесты…»

Позволяет прогнать не всё, а нужную часть — экономит время.

  • Слева — «Сущности»: отметьте нужные; есть «— выбрать все сущности —».
  • Справа — «Виды тестов»: Поля формы, Создание, Изменение, Удаление, Лог. удаление, Архивирование, Валидация (все обязательные), Валидация (частичная), Поиск (все варианты), Гриды (все варианты).
  • «Превью фильтра Surefire (-Dtest=)» внизу показывает в реальном времени, что именно запустится.
Если не отмечен ни один вид теста — запускаются все тесты выбранных сущностей. Если не выбрана ни одна сущность — программа попросит выбрать хотя бы одну.

Быстрый режим (headless)

Галочка «Быстрый режим (headless)» запускает Chrome без видимого окна — прогон чуть быстрее и не мешает работать за компьютером (удобно для фонового запуска). Снимите галочку, если хотите своими глазами видеть, как тесты кликают по сайту (наглядно, удобно при отладке).

Чтение результатов

Над таблицей — счётчики: Всего, Успешно (и сколько Пропущено), Ошибки. В таблице — строка на каждый тест: Класс, Метод, Статус, Время, Сообщение. Статус подсвечен цветом:

СтатусЦветЗначение

SKIPжёлтыйтест пропущен (условие не выполнимо на этом стенде) — это не ошибка
FAILкрасныйтест упал — в колонке «Сообщение» причина

Панель «Лог» снизу показывает пошаговый журнал и последние строки вывода Maven.

История прогонов

Кнопка «История прогонов» выводит в лог список прошлых запусков из локальной базы — дата, имя XML, URL, «Всего / OK / Ошибки» и затраченное время, — а в таблицу подгружает последний прогон. Если запусков ещё не было, в логе будет «История прогонов пуста».

Если что-то пошло не так

Дерево сущностей пустое / кнопки серые

Сначала нажмите «Разобрать XML», затем «Сгенерировать тесты» — кнопки включаются по порядку. «Запустить»/«Выбрать» активны только после генерации.

Статус SKIP (жёлтый) — это ошибка?

Нет. SKIP — это осознанный пропуск (например, нужного элемента нет на данном стенде). В «Ошибки» он не считается. Реальные проблемы — только красный FAIL.

Первый прогон идёт долго

При первом запуске скачиваются зависимости и драйвер браузера. Это разово — последующие прогоны быстрее. Чтобы видеть процесс, можно снять галочку «Быстрый режим».

Синее окно «Windows защитила ваш компьютер» (SmartScreen)

Программа не подписана платным сертификатом, поэтому при первом запуске Windows может показать предупреждение. Нажмите «Подробнее» → «Выполнить в любом случае». Это разовое предупреждение, не вирус.

Первый прогон тестов идёт долго

При самом первом запуске тестов Maven один раз скачивает нужные библиотеки (нужен интернет). Это может занять несколько минут. Последующие прогоны быстрые.

Тесты не запускаются / ошибка про браузер

Убедитесь, что установлен Google Chrome и есть интернет (при первом прогоне автоматически скачивается драйвер ChromeDriver под вашу версию Chrome).

Антивирус блокирует запуск

Добавьте папку программы (например C:\AutoTest) в исключения антивируса.

Более подробное описание (включая ручную установку Java/Maven без скриптов) есть в файле USER_GUIDE.md.
