==========================================================
  AutoTestGenerator — быстрый старт на Windows
==========================================================

Что нужно на компьютере заранее:
  • Google Chrome (для прогона тестов)
  • Интернет (при первом прогоне тестов скачиваются
    зависимости и драйвер браузера)
  Java и Maven уже внутри программы — отдельно ставить не нужно.

Два шага:

  1. Распакуйте этот ZIP в простую папку, например  C:\AutoTest
     (без русских букв и пробелов в пути).

  2. Откройте папку AutoTestGenerator и сделайте двойной клик по
     AutoTestGenerator.exe  — откроется окно программы.

Подробное руководство с пояснениями — в файле  РУКОВОДСТВО.html
(двойной клик, откроется в браузере).

Если Windows покажет синее окно "SmartScreen":
  нажмите "Подробнее" → "Выполнить в любом случае".
  (Программа не подписана сертификатом — это разовое предупреждение,
   не вирус.)

Важно: первый запуск тестов может занять несколько минут — Maven
один раз скачивает нужные библиотеки. Дальше прогоны идут быстро.
