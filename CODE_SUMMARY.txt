3. BaseTest.java — Base Test Infrastructure

Navigation Caching (prevents 10s timeout on every failed test):

private boolean navigationAttempted = false;
private boolean cachedNavigationOk = false;

protected void navigateToEntity(String entityName, String featureName) {
    if (navigationAttempted) {
        navigationOk = cachedNavigationOk;
        return;
    }
    navigationAttempted = true;
    navigationOk = false;
    if ("e3core".equals(TestData.SITE_TYPE)) {
        navigateE3Core(entityName);
    } else {
        navigateGeneric(entityName);
    }
    cachedNavigationOk = navigationOk;
}

E3Core Menu Navigation (recursive submenu descent):

private void navigateE3Core(String entityName) {
    String[] menuButtons = {TestData.SUBSYSTEM_NAME, "НСИ", "Отчёты", "Сервис"};
    for (String menuName : menuButtons) {
        try {
            WebElement menuBtn = driver.findElement(By.xpath(
                "//button[contains(@class, 'x-btn-text')][contains(text(), '" + menuName + "')]"
            ));
            menuBtn.click();
            Thread.sleep(300);
            if (descendMenu(entityName, 3, new HashSet<>())) {
                navigationOk = true;
                return;
            }
        } catch (Throwable ignored) {
            driver.findElement(By.tagName("body")).sendKeys(Keys.ESCAPE);
        }
    }
}

descendMenu() — Recursive submenu search with stem matching:

private boolean descendMenu(String entityName, int maxDepth, Set<String> tried) {
    // Step 1: Find direct menu item (by-word stems to handle declensions)
    String pred = entityStemPredicate(entityName, "text()");
    String itemXpath = "//div[contains(@class,'x-menu')]//span[contains(@class,'x-menu-item-text')][" + pred + "]";
    List<WebElement> directHits = driver.findElements(By.xpath(itemXpath));

    for (WebElement item : directHits) {
        if (!item.isDisplayed()) continue;
        new Actions(driver).moveToElement(item).perform();
        Thread.sleep(500);

        WebElement actionBtn = findVisibleActionBtn("Найти");
        if (actionBtn == null) actionBtn = findVisibleActionBtn("Открыть");
        if (actionBtn != null) {
            actionBtn.click();
            return true;
        }
        item.click();
        return true;
    }

    // Step 2: Not found directly — recurse into submenus
    if (maxDepth <= 0) return false;

    String parentXpath = "//div[contains(@class,'x-menu')]//a[contains(@class,'x-menu-item')]";
    List<WebElement> parents = driver.findElements(By.xpath(parentXpath));
    for (WebElement parent : parents) {
        String parentText = parent.getText().trim();
        if (parentText.isEmpty() || parentText.contains(entityName) || tried.contains(parentText)) continue;

        tried.add(parentText);
        try {
            new Actions(driver).moveToElement(parent).perform();
            Thread.sleep(250);
            if (descendMenu(entityName, maxDepth - 1, tried)) return true;
        } catch (Exception ignored) {}
    }
    return false;
}

Word Stem Matching (handles Russian declensions):

private String entityStemPredicate(String entityName, String textFn) {
    String[] words = entityName.split("[\\s/]+");
    StringBuilder sb = new StringBuilder();

    for (String word : words) {
        if (word.isEmpty()) continue;
        // Stem: last 2 chars dropped for long words, exact match for short
        String stem = word.length() <= 3 ? word : word.substring(0, word.length() - 2);
        sb.append("contains(").append(textFn).append(", '").append(stem).append("') and ");
    }
    return sb.toString();  // e.g. "contains(text(),'Должностн') and contains(text(),'лиц')"
}

5. Key Decision: Cache-Based Navigation

Problem: After resetState() closes grid, all tests re-navigate. Each navigation
takes 8-10 seconds. 40+ tests × 10s = 400s.

Solution: Cache navigationAttempted flag in BaseTest.

Per test method:
- @BeforeEach resetState() opens fresh grid
- navigateToEntity() checks cache, skips if already tried
- Subsequent @BeforeEach calls reuse grid
- Grid persists across @BeforeEach boundaries

Result: ~40s for 40 tests (1s + navigation) vs ~400s (all navigate).

Code in setUp:
if (page == null) {  // First test only
    navigateToEntity(...);
    page = new EntityPage(driver);
}
assumeNavigated();  // All tests verify navigation ok (cached or real)

6. ExtJS 3 Quirks Handled

Issue: Selenium sendKeys not accepted by ExtJS input masks
- Mask filter rejects synthetic events
- Only real user input works (architecture limitation)

Solution: Soft-fail with logging instead of assert

Issue: PropertyGrid inline editor not PageFactory-friendly
- No id/name attributes on <input>
- Requires DOM walking: cell → row → cells.get(1).click() → wait for editor

Solution: dblclick value cell, find topmost visible input in DOM, sendKeys

Issue: Menu item text varies (declensions: singular/plural/genitive)
- "Должностное лицо" (menu) vs "Должностные лица" (title)
- Can't use exact text match

Solution: Word-stem matching (first N chars, typically 4-6 chars)

8. Test Flow (Full Test Execution)

1. beforeAll():
   - Initialize driver from SharedDriver
   - Login performed once (SharedDriver.performLogin)
   - Subsystem selected once (SharedDriver.selectSubsystem)

2. @BeforeEach setUp():
   - resetState() — close any open dialogs/grids
   - if (page == null) → navigateToEntity() [1st test only]
   - Create page object
   - assumeNavigated() [soft-fail if nav failed]

3. @Test method():
   - menuAction("EntityName", "Добавить") → open add dialog
   - page.fillAllFields()
   - clickButtonByText("Готово") → submit
   - Thread.sleep(1000) → wait for post-save processing
   - assertFalse(isErrorPresent()) — no errors
   - assertTrue(rowsAfter >= rowsBefore) — row count increased

4. @AfterEach (implicit):
   - JUnit does not call @AfterEach on Assumption.skip()
   - Manual cleanup in setUp() via resetState()

5. After all tests:
   - SharedDriver.getDriver().quit() via shutdown hook

10. Error Handling Pattern

All user interactions wrapped in try/catch/finally:

try {
    // Selenium action
    WebElement el = driver.findElement(...);
    el.click();
} catch (Exception e) {
    System.out.println("Action failed: " + e.getMessage());
    // Soft-fail: continue test with next assertion
}
finally {
    driver.manage().timeouts().implicitlyWait(Duration.ofSeconds(2));
}

No explicit exception throw — tests self-diagnose via assertions.
