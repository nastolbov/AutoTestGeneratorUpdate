# Раздел 1.3 — анализ процесса обработки информации, методы и алгоритмы (ч/б)

Текст, схемы и таблицы построены **по фактическому коду программы** AutoTestGenerator
(пакеты `ru.autotestgen.*`), а также по руководству оператора платформы **E3Core**
и руководству пользователя тестируемой АИС «Гаражно-строительные кооперативы».
Раздел описывает **логику** обработки данных и выбранные методы/алгоритмы; конкретные
классы и методы исходного кода здесь **не приводятся** — их проектирование выполняется
в разделах 1.4–1.5. Все схемы — **чёрно-белые**.

## Что описано

- источник данных — платформа E3Core (метамодель → интерфейс) и тестируемая АИС ГСК;
- конвейер обработки: разбор XML → классификация → генерация → запуск → анализ;
- входная XML-модель: структура и фрагмент-пример (листинг);
- потоковый разбор XML (StAX);
- классификация сущностей (PRIMARY / CHILD / REFERENCE_DICTIONARY);
- паттерн **Page Object**;
- шаблонная генерация тестового проекта и алгоритм именования (транслитерация);
- подбор тестовых данных по типу и маске;
- состав формируемых проверок (покрытие);
- запуск тестов (Maven Surefire) и анализ отчётов, хранение истории (SQLite).
