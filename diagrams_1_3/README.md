# Раздел 1.3 — анализ процесса обработки информации, методы и алгоритмы

Текст, схемы и таблицы построены **по фактическому коду программы** AutoTestGenerator
(пакеты `ru.autotestgen.*`), а также по руководству оператора платформы **E3Core**
и руководству пользователя тестируемой АИС «Гаражно-строительные кооперативы».
Раздел описывает **логику** обработки данных и выбранные методы/алгоритмы; конкретные
классы и методы исходного кода здесь **не приводятся** — их проектирование выполняется
в разделах 1.4–1.5.

**Схемы алгоритмов выполнены по ГОСТ 19.701-90 (ИСО 5807-85)** «Схемы алгоритмов,
программ, данных и систем»: терминатор (овал) — начало/конец; процесс — прямоугольник;
решение — ромб; предопределённый процесс (подпрограмма) — прямоугольник с двумя
вертикальными линиями; данные (ввод-вывод) — параллелограмм; линии потока — сверху
вниз со стрелками. Все схемы чёрно-белые.

## Форматирование документа

- рисунки и их подписи — по центру, шрифт подписей 14;

Зависимости: `graphviz` (бинарь `dot`), Python-пакеты `python-docx`, `Pillow`,
шрифт DejaVu Sans (кириллица).

cd scripts
python3 gen_graphviz.py   # ris_1..ris_9 (схемы по ГОСТ + фрагмент XML)
