# Раздел 1.4 — диаграммы спецификации (исправленные)

Диаграммы и отчёт построены **по фактическому коду программы** AutoTestGenerator
(пакеты `ru.autotestgen.*`) и по правилам построения UML-диаграмм из методички
(раздел 6: варианты использования, контекстная модель, диаграммы последовательности
системы, диаграммы деятельности).

На этапе спецификации (раздел 1.4) система рассматривается как **«чёрный ящик»**:
фиксируются внешнее поведение и понятия предметной области, **без** кнопок, полей
ввода и внутренних классов/методов (они появляются в разделах 1.5–1.6).

## Воспроизведение

Зависимости: `graphviz` (бинарь `dot`), Python-пакеты `python-docx`, `Pillow`,
шрифт DejaVu Sans (кириллица).

```bash
cd scripts
python3 gen_graphviz.py   # ris_1, ris_2, ris_7, ris_8 (+ actor.png — артефакт)
python3 gen_ssd.py        # ris_3..ris_6 (диаграммы последовательности)
python3 build_docx.py     # Раздел_1.4_исправленный.docx
```
