# Раздел 1.4 — диаграммы спецификации (исправленные, ч/б)

Диаграммы и отчёт построены **по фактическому коду программы** AutoTestGenerator
(пакеты `ru.autotestgen.*`) и по правилам построения UML-диаграмм из методички
(раздел 6). Система рассматривается как **«чёрный ящик»**: без кнопок, полей
ввода и внутренних классов/методов. Все диаграммы — **чёрно-белые**.

Особенности:
- диаграммы последовательности системы — **только события Пользователь → Система**
  (без обратных стрелок), по одной диаграмме на каждый вариант использования,
  включая «include»;
- **контекстная диаграмма классов (`ris_2_context_class.png`) взята из ВКР**
  (`Столбов_ВКР.docx`) без изменений;
- на каждое действие с системой — отдельная таблица операции с разделом
  «Исключения» (альтернатива);
- в «Типичном ходе событий» нет пустых ячеек: последовательные отклики системы
  сгруппированы в одной ячейке; альтернативы нумеруются номером шага без буквы.

## Воспроизведение

Зависимости: `graphviz` (бинарь `dot`), Python-пакеты `python-docx`, `Pillow`,
шрифт DejaVu Sans (кириллица).

```bash
cd scripts
python3 gen_graphviz.py   # ris_1, ris_9, ris_10 (ВИ, System, деятельность)
python3 gen_ssd.py        # ris_3..ris_8 (диаграммы последовательности, ч/б, без возвратов)
python3 build_docx.py     # Раздел_1.4_исправленный.docx
# ris_2_context_class.png извлечена из Столбов_ВКР.docx и НЕ перегенерируется
```
